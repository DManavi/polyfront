**Polyfront** is a framework-agnostic JavaScript and TypeScript library designed to simplify the development, integration, and composition of microfrontend applications.

Build your applications independently, use the technologies that best suit your needs, and bring them together into a cohesive web experience — without being tied to a particular frontend framework.

## ✨ Vision

Polyfront aims to make microfrontend architecture simple, flexible, and accessible without introducing unnecessary complexity or framework dependencies.

## 🚀 Core principles

- 🌐 **Framework agnostic** — Bring your own framework, or use vanilla JavaScript.
- 🧩 **Composable** — Build larger applications from independent frontend units.
- 📦 **Independent** — Keep applications loosely coupled and independently managed.
- 🔌 **Extensible** — Adapt to different architectural requirements.
- 🛡️ **TypeScript first** — Prioritize type safety and developer experience.
- 🪶 **Minimal by design** — Focus on composition without unnecessary abstractions.
- 🤝 **Interoperable** — Enable different frontend technologies to coexist.

## 💡 Why Polyfront?

Frontend applications shouldn't have to share the same framework to share the same experience.

Polyfront embraces the freedom to build independently while providing a foundation for bringing applications together.

**Build independently. Compose seamlessly.**
